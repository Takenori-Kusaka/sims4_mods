# Kokor No Notify

通知・電話・ダイアログを自動応答し、ゲームプレイの中断を最小化するScript MODです。

詳細は [docs/README.md](docs/README.md) を参照してください。

## クイックスタート

```powershell
cd mods/no_notify
npm ci
npm run build:script          # ビルド
npm run deploy:script         # ビルド + デプロイ
npm run test                  # テスト
```

## チートコマンド

| コマンド | 説明 |
|----------|------|
| `kokor_no_notify.toggle` | ON/OFF切替 |
| `kokor_no_notify.status` | 設定表示 |
| `kokor_no_notify.help` | ヘルプ表示 |
